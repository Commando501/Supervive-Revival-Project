  ARM D: CDO(Default__Pawn).AIControllerClass poke -> ONE SpawnAIFromClass -> LokiBotController -> restore
  -> ARM B/C (PlayerState) -> ARM F (LivingState=1 + UpdateCharacterControllable: gate opens) ->
  ARM G (CDO subobject borrow into bot +0xF00/+0xF08/+0xF10 + six attrs, MoveSpeed=487) -> K1 mask 0x2
  (player +0xF08 -> the same CDO set) -> [RCPT] getter receipts on both pawns -> ARM H (poison +0x16B0,

  PEAK line -> ARM H verdict (cosmetic here) -> [BS] done.
