THE CRASH INSTRUCTION
---------------------
  +0x296F58B: mov  r15d, [rdi+0x10]
  +0x296F58F: xor  eax, eax
  +0x296F591: mov  rcx, [rbx+0x28]        <<< CRASH, rbx = 0 (reads addr 0x28)
  +0x296F595: lock cmpxchg [rcx], r12     ; atomic swap on the (null) object's ptr
  +0x296F59A: shr  rax, 0x1a              ; test bit 26 of old value (residency state)
Data flow to the null:
  rdi = *(*(rsi+0x38))         ; object pulled from a slot/container at rsi->0x38
  rbx = rdi->[8]              ; a sub-pointer of that object -> IS NULL
  crash reads rbx->[0x28].
Surrounding code is UE's refcounted-RHI-resource smart-pointer boilerplate
(AddRef = `lock inc [obj+8]`, Release = `lock xadd [obj+8]` then vcall dtor when
refcount hits 1). So rbx is a refcounted RHI object that was never populated.
