★ PARAM-PASSING RECIPE (RE'd + verified — the reusable capability)
------------------------------------------------------------------
Calling a native UFunction WITH parameters via the direct thunk. It's UObject::ProcessEvent's "compiled-in"
path (Code==NULL branch) done by hand:
  1. Build a params frame (Locals): a zeroed buffer; write each INPUT param value at its FProperty
     Offset_Internal (@ FProperty+0x44). (Return value is written to the r8 Result buffer, not the frame.)
  2. FFrame fields: Object(+0x18)=Context(this; ignored for a static fn), Node(+0x10)=UFunction,
     Code(+0x20)=NULL, Locals(+0x28)=params frame, PropertyChainForCompiledIn(+0x88)=Function.ChildProperties
     (= *(UFunction+0x58) = the first param FField). Clear MostRecentProperty(+0x30) /
     MostRecentPropertyAddress(+0x38) / MostRecentPropertyContainer(+0x40) (the thunk also zeros +0x38/+0x40).
  3. Call the thunk: ((void(*)(void* Ctx, void* FFrame, void* Result))(UFunction.Func@+0xE0))(Ctx,&frame,&res).
The thunk's Code==0 branch reads FFrame+0x88, walks Property->Next(+0x18) per param, and StepExplicitProperty
copies (non-out) / addresses (OUT) from Locals+Offset. VERIFIED against the GetMissionModel + factory thunks.
