THE GO/NO-GO, SHARPENED WITH HARD NUMBERS (the honest read)
-----------------------------------------------------------
The stub-half is done and clean. The DECISIVE test — does the client ACCEPT a Loki-typed PC and
does TryGetLocalLokiController fire — needs the live client (UAC + Steam; not doable in this
autonomous session). What the headless work already sharpens:

  * PROP reconstruction (tractable): the replicated subset of LokiBaseController(2)+
    LokiPlayerController(78) is a small handful; capture it live (rep_expand_class.py) and add in
    field order, iterating on "Invalid replicated field N" like the S70 GameState mirror. This is
    the SAME method that already succeeded for GameState.

  * RPC reconstruction (THE WALL, confirmed bidirectional): stock APlayerController already has
    81 net functions; the client's LokiPlayerController adds its own (ServerVerifyViewTarget's
    40-param modified sig — already handled via the Loki.cpp inject — plus more). Unlike GameState
    (one-way data, 0 RPCs — which is WHY that mirror was clean), the PC is RPC-heavy and
    BIDIRECTIONAL: once the client's local PC is a LokiPlayerController it SENDS Loki PC RPCs to
    the stub, each addressed by net-index into the ClassNetCache. If the mirror's NetFields (RPC
    set, name-sorted, count) don't match the client's, the index resolves wrong / overflows →
    SERVER-side receive desync → connection close. This can't be suppressed like a one-way
    server->client RPC. It is exactly the S41 wall.

  MITIGATION that could make it bounded (test on the live run): NetworkChecksumMode=None means no
  fingerprint reject, and NetFields are NAME-SORTED. If the mirror declares the SAME-NAMED net
  functions as the client's LokiPlayerController (even empty/stub bodies), the name-sorted index
  space aligns and incoming RPCs route to the right stub function; only the RPCs the client
  actually SENDS EARLY need their (modified) signature reconstructed to parse without overflow.
  So the reconstruction is (a) enumerate the client's LokiPlayerController net functions live
  (func_enum.py / find_ufunc.py), (b) declare matching-named UFUNCTIONs on the mirror, (c) match
  the signature only for the ones fired early. Bounded, but per-RPC and needs live data.
