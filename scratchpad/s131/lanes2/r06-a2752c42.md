## FOUR FURTHER DEFECTS

### D1 — "For this function: one poke" is **REFUTED**. There is no poke.

The report's own transcription proves it and it did not close the loop:
```
055cd55b  mov rax,[r14+0xc0]     ; cached WORLD
055cd565  jne .have              ; if null:
055cd56a  call 0x35afc40         ;   GetWorld(component)
055cd56f  mov rcx,rax            ; rcx = the WORLD  <-- the fold's ARGUMENT
055cd572  call 0xf7eb50          ; 33 c0 c3 -- ignores rcx, returns 0 unconditionally
```

`[r14+0xC0]` is the **argument**, not the return. No aligned data write anywhere in the process changes what `33 c0 c3` returns. The available routes are a `.text` write at `0x55CD572` (the project's 7/8-lethal class), a `UFunction.Func` swap on exec thunk `0x5456380` that *reimplements* the body, or hand-executing the tail. **"One fold away" is right; "one poke" is not, and in this repo's vocabulary those are different hazard classes.** [M]

## NEW MEASURED FINDING THE REPORT MISSED — it answers the parent's question directly

The parent asked: *what did `0xF7EB50` replace, and is there any other route to a round game mode object on this client?*

I xref'd the IsA helper `0x55C7DD0` (3 rel32 callers in the decrypted 55 %) and one of them, **`0x55CE152` — same class, same `[obj+0xC0] ?: 0x35AFC40` world prologue, ~2.4 KB away — does the job in real, unstripped code:**
```
055ce152  mov rax,[rbx+0xc0]        ; cached world
055ce15c  jne .have ; else call 0x35afc40
055ce166  mov rdi,[rax+0x250]       ; <-- World->AuthorityGameMode
055ce170  je  .bail
055ce172  mov rcx,rdi
055ce175  call 0x55c7dd0            ; IsA(ALokiRoundGameMode)  -- the SAME helper
055ce17e  mov [rbx+0xe0], rdi       ; cache the round game mode on the component
```
And `UWorld+0x250` is **[M]**, not inferred: `UGameplayStatics::GetGameMode` (record-table impl `0x37D7BF0`, multiplicity 1) is `…GetWorldFromContextObject…; mov rax,[rax+0x250]; ret`, with its sibling `GetGameState` (`0x37D7D00`) reading `[rax+0x258]` — the `UWorld::GameState` offset this repo already holds [M]. Two adjacent fields, one independent function, exact match.

Therefore:
- **[M] A round game mode IS reachable on this client**, by the ordinary `World->AuthorityGameMode` + `IsChildOf(ALokiRoundGameMode)` path, and this very class already does it.
- **[I, strong] What `0xF7EB50` replaced at `0x55CD572` is a `GetRoundGameMode(UWorld*)` helper equivalent to `Cast<ALokiRoundGameMode>(World->AuthorityGameMode)`** — the sibling inlines exactly that, from the same cached-world source, into the same IsA helper. Stronger than the report's bare naming, and now supported by code rather than by the error string.
- **[I] `ULokiRideableComponent+0xE0` is a cached round-game-mode slot.** Poking it does **not** unblock `AuthPlayerEnterWorldAttachedToRidable` (D1), but a `Func`-swap reimplementation can read it instead of calling the fold — which removes the last unknown from the reimplementation route.
